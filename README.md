# ArmorHud
[![GitHub Release](https://img.shields.io/github/v/release/redart15/armorhud?labelColor=134210&color=751919&cacheSeconds=120)](https://github.com/Redart15/ArmorHud/releases)
[![GitHub last commit](https://img.shields.io/github/last-commit/Redart15/ArmorHud?labelColor=134210&color=751919&cacheSeconds=120)](https://github.com/Redart15/ArmorHud/commits/8.0/)

It adds a simpler and more visually appealing version of the armor bar from 7.3.
Players have the choice between rendering the actual icon of the item they are wearing or having an tinted icon showing the slots durability.
The default armor hud is disabled.
